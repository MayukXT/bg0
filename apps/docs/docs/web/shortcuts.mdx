---
title: Keyboard shortcuts
description: Every shortcut in the web app. Hands never have to leave the keyboard.
---

Shortcuts work whenever focus is not inside a text field. On Windows and Linux, use <kbd>Ctrl</kbd> where <kbd>⌘</kbd> is shown.

## Getting an image in

| Keys | Action |
| --- | --- |
| <kbd>⌘O</kbd> | Open the file picker |
| <kbd>⌘V</kbd> | Paste an image from the clipboard |

## Comparing

| Keys | Action |
| --- | --- |
| <kbd>Space</kbd> | Hold to peek at the original |
| <kbd>←</kbd> <kbd>→</kbd> | Slide the compare line. Tap to nudge, hold to glide |
| <kbd>Shift</kbd> + <kbd>←</kbd> <kbd>→</kbd> | Slide faster |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | Compare, result, original |

## Getting an image out

| Keys | Action |
| --- | --- |
| <kbd>⌘S</kbd> | Download the PNG |
| <kbd>⌘C</kbd> | Copy the PNG to the clipboard |
| <kbd>Esc</kbd> | Clear and wait for the next image |
